# Getting started

Immich is high performance, self-hosted image and video management software. It runs on your own hardware, which means there is a machine to prepare before there is an Immich to use.

## Before you begin

Review the [hardware and software requirements](/reference/requirements). Immich needs a reasonably capable machine — the machine learning features in particular are memory-hungry — and Docker with the Docker Compose plugin.

## Install Immich

Once the machine is ready, pick an installation method from [Install and upgrade](/install/). Docker Compose is the recommended method and is what the rest of the documentation assumes.

If you would rather try Immich before committing to a deployment, [Quick start](/install/quick-start) walks through the shortest path to a working instance.

## After installing

[Next steps](/introduction/next-steps) covers registering the admin user, setting up backups, and the optional features worth knowing about.
